# イベント本文監査

## 共通イベントの修正

- `press_gang_conscription`: 英国海軍の徴募を欧州各国・1945年まで適用していた。対象を近世・近代ブリテンの1700〜1815年へ絞り、本文も船員経験者の徴募に統一した。1700年はこのシナリオの採用開始年で、制度の創設年ではない。職業履歴の条件は未実装なので、船員経験はイベント導入で提示する。根拠：[英国議会](https://www.parliament.uk/about/living-heritage/transformingsociety/private-lives/yourcountry/overview/pressgangs-/)、[国立海事博物館](https://www.rmg.co.uk/collections/objects/rmgc-object-100761)。地域横断と1815/1816年の境界を回帰検証する。
- `rotten_tooth_infection`: 全地域共通なのに床屋外科医・鍛冶屋を標準の治療担当としていた。担当者を中立な表現にし、地域ごとの違いを明記。ロンドンの「Teeth」死亡分類から成人の歯性感染症の頻度を断定する説明を削除した。
- `collective_punishment`: 中国にも出る選択肢の「人別帳・無宿」を、土地を失った逃亡生活という表現へ変更。
- `serf_master_whim`: ローマやカリブにも出る選択肢から、中世欧州都市の法的慣行を連想させる「都市の空気は自由にする」を削除。

## 征服・戦争の適用範囲

- `modern_cold_war_conflict`: 南・東南アジア、サハラ以南、中東・北アフリカの全対象国に年代指定なしで出ていた内戦を、現在のバングラデシュに当たる地域の1971年に限定し、独立戦争中の民間人の避難・生活維持へ本文を変更。[国連バングラデシュの歴史](https://bangladesh.un.org/en/about/about-the-un)。避難先として隣国を約束しつつ国内都市へしか移動しなかった効果は削除し、近くの避難先を探す表現にした。実際の国境越え・難民状態のモデルは未実装。従来の冷戦というIDは互換のため維持する。他国の紛争を否定せず、別の出典付き事件として今後追加する。
- `industrial_conscription_order`: 1800年から出得た日本の赤紙召集を1937〜1944年、20歳以上へ限定。徴兵検査と臨時召集を混同しない本文へ変更。[国立公文書館の1873年徴兵令解説](https://www.archives.go.jp/ayumi/kobetsu/m06_1873_01.html)、[平和祈念展示資料館](https://www.heiwakinen.go.jp/about/josetsu-heishi/)。期間はこのシナリオの採用範囲であり制度の存続期間ではない。1945年は現代区分へ移るため今回の近代シナリオでは対象外。免除・召集対象・年齢の法改正すべてを再現してはいない。

- `ww1_1914`: 米国・イタリアにも1914年から同じ召集が出ていた。イタリア1915〜1918年、米国1917〜1918年を別イベントに分けた。また志願か工場勤務かという選択内容に合わせ、召集令状の到着ではなく戦時の仕事と軍務の選択へ書き換えた。英国の1916年以前にも一律の徴兵があるとは扱わない。[英国陸軍博物館](https://www.nam.ac.uk/explore/first-world-war)、[米国国立公文書館](https://www.archives.gov/research/military/ww1/draft-registration)。工場事故の死因に1914年からスペイン風邪を混ぜていた表現も削除。兵役免除・職業割当・各国の徴兵年齢の再現は未対応。
- `industrial_total_war_air_raid`: 1937年から欧州・日本・中国・ロシア全域に出ていた同じ空襲を、東京1945年の事件へ絞った。ゲームでは1945年が現代区分なので `mod_japan` を対象にする。ロンドン1940〜1941年のブリッツは `london_blitz_1940` に分割。[国立公文書館の東京大空襲解説](https://www.archives.go.jp/ayumi/kobetsu/s20_1945_01.html)、[Historic Englandのブリッツ解説](https://historicengland.org.uk/whats-new/features/second-world-war-and-blitz/)。都市指定と年境界を検証する。他都市の空襲がなかったという意味ではなく、今回のモデルで具体的に表現する都市・年を限定した。月日、都市内の地区差、避難後の移住状態は未対応。確率は引き続きゲーム推定値。

- `mongol_1220`: 欧州・中国・イスラム圏全域で1219〜1260年に発生していた侵攻を、1220年のブハラ・サマルカンドへ限定。[NASAのサマルカンド史解説](https://eol.jsc.nasa.gov/Collections/EarthObservatory/articles/SamarkandUzbekistan.htm)、[UNESCOの都市遺跡解説](https://whc.unesco.org/en/list/603)。他地域への侵攻すべてを一つの事件で再現しない。
- `mongol_baghdad_1258`: 1258年のバグダード攻略を別イベントにした。バスラや他国、別年に出さず、降伏すれば町が焼かれないという旧結果も引き継がない。[Metropolitan Museumの解説](https://www.metmuseum.org/pt/essays/the-legacy-of-genghis-khan)。生存確率は従来のゲーム設定を継承した暫定値で、事件の実測生存率ではない。
- `early_modern_thirty_years_mercenary`: 三十年戦争による村の略奪を、ブリテンなどを含む欧州全域からドイツ地域へ限定。[ドイツ歴史博物館](https://www.dhm.de/en/exhibitions/permanent-exhibition/reformation-and-the-thirty-years-war/)、[米陸軍大学の解説](https://warroom.armywarcollege.edu/articles/thirty-years-war/)。これはゲーム内の対象地域を保守的に絞るもので、戦争全体の戦域や他国の参戦を否定するものではない。

## ライフサイクル本文の修正

- `work_choice_youth`: 前近代向けの徒弟・奉公を現代にも適用していたため、古代〜近代へ限定。現代は16〜22歳向けの `modern_youth_path` を追加し、働きながらの学習・収入優先・実地で技術を学ぶ選択にした。全地域に同じ学校や雇用制度があるとは仮定しない。効果値はゲーム上の設定。
- `tax_burden`: 収穫の納付を農村の農民身分へ限定し、都市や職人への誤適用を防いだ。全地域一律の徴収割合や十分の一税という説明も削除。職業変更後の実際の農業従事までは追跡していない。
- `midlife_crisis_30s`: 全地域共通のため、現代にも社会保障が存在しないという説明を修正。都市住民が畑を取得して収穫を増やす結果を、仕事道具の取得へ変更した。

- `marriage_serf_merchet`: 全中世欧州へ広げていた婚姻納付金を、中世ブリテンの農村へ限定した。本文も、隷属的な借地人の家への納付要求として記述し、全農民に共通する義務という断定を削除。[英国国立公文書館の荘園文書解説](https://www.nationalarchives.gov.uk/archives-sector/finding-records-in-discovery-and-other-databases/manorial-documents-register/a-guide-to-manorial-documents/)。ブリテン内部の荘園差・自由身分と隷属身分の区分は未実装であり、全村落の慣行を再現するものではない。
- `marriage`: 全文化共通の持参金・初対面の婚礼という前提を削除し、縁談を受けるかの選択として記述。
- `childbirth_old`: 1945年まで消毒も帝王切開も存在しないという誤った断定と、全時代・全地域共通の妊産婦死亡率の説明を削除。
- 現代の男女両方の出生イベント: 全世界で妊産婦死亡が前近代の100分の1、成人生存95%以上という一律の説明を削除し、医療へのアクセスの差を明記。[WHOの妊産婦死亡の解説](https://www.who.int/news-room/fact-sheets/detail/maternal-mortality)。病院での安全を保証する選択肢の説明も変更した。

生存確率・配偶者死亡確率は今回変更していない。出産イベントの危険度と医療の選択肢を国・年代・所得層ごとに分ける設計は引き続き必要。史実の説明とゲーム内の固定確率を同一視しない。

## 出産確率の共通処理による上書きを修正

この節は固定確率の処理修正時点の記録。その後、現代の出産は [国別・年別の母体リスクモデル](./maternal-risk.md) に対応した。以下の男女差は新しい現代の選択経路では解消済み。古い時代の出産や医療格差の課題は残る。

現代の女性側の病院出産に設定された生存確率0.996が、共通の健康補正と上限0.99で上書きされていた。`ChoiceOption.survivalModel: 'fixed'` を追加し、この選択肢では設定値をそのまま使う。健康0・50・100で判定境界0.996を検査する。乳児死亡率、年次ハザード、他の選択肢の健康補正は変更しない。

0.996は引き続き既存のゲーム推定値で、公的な国別統計を反映した値ではない。男性側の妻の死亡確率0.002との不一致、古い出産イベント、医療アクセスの地域・所得差は未解決。今回の変更で出産モデル全体が較正されたとは扱わない。

次のデータ設計では、[WHOの妊産婦死亡比の定義](https://www.who.int/data/gho/indicator-metadata-registry/imr-details/26)が妊娠・出産とその後の期間を含む人口集団の指標であることに留意する。国の平均値を、病院を選んだ個人だけの死亡確率として表示しない。資料のある国・年、資料以前、将来の据え置きを分け、出典・適用範囲を保持する必要がある。

これは共通イベントの初回監査であり、全イベントの監査完了を意味しない。狩猟権・隷属身分・連帯納税の制度差、医療の史料、各時代モジュールとライフサイクル本文の監査を続ける必要がある。イベント内の生存確率は史料から得た治療効果ではなくゲーム上の値であり、今回変更していない。
