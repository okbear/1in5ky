# 家族の命名モデル

## 修正した問題

旧実装では、中国の一部の人名リストに姓を含む名前と個人名、皇帝の年号・称号などが混在し、主人公・父母・弟妹・配偶者・子を独立に抽選していた。このため父子の姓まで無関係になった。

`engine/names.ts` に命名規則を集約し、`PersonalName` に個人名 `givenName`、現在の姓 `familyName`、出生姓 `birthFamilyName`、表示規則 `convention` を保持する。画面用の `name` はそこから生成する。中国の対象リストと中世日本のリストを個人名に統一した。文字列の先頭を機械的に姓と解釈する処理は使わない。

主人公の `birthName` は変更しない。結婚などで現在名が変わった場合、人生画面・死亡画面に出生時の名前を併記する。保存済みのメモリアルの文字列は書き換えない。

## 対応する規則

| 対象 | 親子・婚姻の扱い |
| --- | --- |
| 漢代以降の中国、現代台湾の対象プロファイル | 父・主人公・弟妹は父系の姓を継ぐ。母と配偶者は生家の姓を保持。主人公が女性の場合、新しく生まれる子は生存中の夫の姓を継ぐ |
| 現代韓国の対象プロファイル | 同様に父系の継承と夫婦の姓の保持を基本とする |
| 日本・1875年より前 | 庶民は個人名を表示。1000年以降の武士・上層身分は名字を表示し、妻は生家の姓を保持する簡略モデル |
| 日本・1875年以降 | 公称名字を表示。既存の人生で1875年を迎える場合も生存家族の名字を補い、変更を記録する |
| 日本・1898年以降 | 夫婦が同じ氏を用いる。ゲームでは夫の氏を世帯の既定値とする |
| その他・古代中国 | 既存の個人名表示を維持。未対応の命名慣行へ東アジアの姓制度を当てはめない |

中国の父系継承・妻の姓の保持は [中国文化の人名解説](https://en.chinaculture.org/library/2008-02/05/content_23824.htm)、韓国の父系を基本とする姓制度と例外は [韓国憲法裁判所の解説](https://english.ccourt.go.kr/site/eng/ex/bbs/View.do?bcIdx=984870&cbIdx=1142) を参照。日本の1875年の公称義務化、1876年の妻の生家の氏、1898年の家の氏は [法務省の歴史解説](https://www.moj.go.jp/MINJI/minji36-02.html) に基づく。

家族の命名文化は出生時のプロファイルに結び付け、時代区分や居所の変更だけで別文化の名前を付けない。結婚時には新しい夫婦だけを改姓対象とする。再婚時も既存の子・以前の配偶者・出生家族の名前は変更しない。制度移行による更新でも故人の名前は保持する。個人名の重複は家族全体で避ける。

## 簡略化と未対応

- 日本の1875年以前の表示は、公称の扱いを簡略化したもの。庶民が私的な名字を持たなかったという意味ではない。制度移行は年単位で扱い、個別の戸主・家制度や月日までは再現しない。
- 現代日本の婚姻では法制度上は夫または妻の氏を選べる（[法務省の解説](https://www.moj.go.jp/MINJI/minji36)）。ゲームの夫の氏という既定値は、全婚姻の実態を表すものではない。
- 母系の姓、養子、婿入り、再婚時の子の個別改姓、複姓の連結、民族・宗教・階層ごとの例外は未対応。夫不在時の子の姓は母の姓へフォールバックする。
- 台湾は現在のプロファイルの漢語名を対象とし、先住民族などすべての命名慣行を網羅しない。古代中国の姓・氏・称号を現代の姓へ変換しない。
- 人名リストと姓の候補は表記例。各年代・階層の頻度分布や、すべての候補の厳密な使用年代を再現した辞書ではない。他文化の `personal-only` は表示上のフォールバックであり、その文化に姓がないという意味ではない。

## 検証

命名テスト16件で父子・弟妹の継承、配偶者の姓、男女双方の結婚と出生、日本の制度移行、出生名・故人・再婚前の子の保持、未対応文化への誤適用を検査する。E2Eではデスクトップとモバイルの両方で、中国の主人公・父の姓の一致と母の別姓、説明文を確認する。

姓の抽選追加と人名リストの修正により乱数消費が変わるため、モデルv2の人生トレース期待値を明示的に更新した。死亡率の式や乳児ハザードは変更していない。
