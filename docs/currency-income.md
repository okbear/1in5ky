# 通貨と所得の表示

国別分割では、親地域の `annualBaseIncomeUnit` を継承しながら `currencyUnit` を国別に変更していた。その数値をそのまま国別通貨の年収として表示すると、単位の換算も国別較正も済んだように見えてしまう。

`presentation/income.ts` は通貨の名称、ゲーム上の収入額 `modeledIncome`、出典条件を満たす名目所得 `nominal` を区別する。出生画面・人生画面では従来の収入額と現代円の目安を併記する。推定の説明はトップの共通注記に集約し、画面ごとに換算未整備の説明を表示しない。

収入額は既存の基準額、階層、財産の倍率に基づくゲーム推定値。現代円の生活実感も `modernFeelJpy` に基づく独立の推定で、表示上の「現代換算」は実際の為替換算ではない。出典条件を満たす `nominal` と同一視しない。国別・年別の数値較正は引き続き必要で、今回の表示復帰では収入・財産の計算を変更しない。

## 年代別の通貨名

日本は、対象プロファイルの1603〜1870年では両・匁・文などの金銀銭貨、1871年は円の導入と移行期、1872年以降は円を単位として表示する。[日本銀行貨幣博物館のFAQ](https://www.imes.boj.or.jp/cm/history/historyfaq/)、[国立公文書館の新貨条例解説](https://www.archives.go.jp/ayumi/kobetsu/m04_1871_03.html)。1871年は月単位の切替を省略する。円の表示は旧貨幣が即座にすべて通用停止したことを示さない。1603年はこの表示規則の採用下限で、両・文などの成立年ではない。両を円へ数字だけ引き継ぐ換算は行わない。

古代エジプトの「デベン銅貨」は、金属の重量・価値単位と穀物配給という表記へ訂正した。[UCLの重量単位解説](https://www.ucl.ac.uk/museums-static/digitalegypt/weights/weight.html)。同じ名称でも時代によって重量が異なり、現代の硬貨のような単位として扱わない。

現代のフランス・イタリアと1990年以降のドイツについて、1998年以前は旧通貨、1999〜2001年は旧通貨の現金と帳簿上のユーロ、2002年以降はユーロを表示する。[ECBの導入史](https://www.ecb.europa.eu/euro/intro/html/index.nb.html)、[2002年の現金切替](https://www.ecb.europa.eu/euro/changeover/2002/html/index.en.html)。1990年以前のドイツは東西・占領地域差を一つの通貨へまとめない。年単位のため2002年初めの並行流通の月日は表さない。将来は現在の制度を継続するゲーム上の仮定。

この表記の切替で名目収入を換算したり、元の数値へユーロの名前だけを付けたりしない。通貨史未対応の地域はプロファイルの表記を「期間内の例」と明示する。各国のデノミネーション、その他の制度変更は今後の対象。

将来、出典付き基準額を追加する場合は国・年・通貨単位と階層倍率の整合性も確認する。現在の `sourced` は基準額の出典状態で、個人の所得が観測値であることを意味しない。
