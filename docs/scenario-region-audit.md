# シナリオ・地域混在の監査と分割

## 原因

「シナリオ」は独立した単位ではなく、出生時に選ばれた `RegionProfile` と全イベント共通配列 `ALL_EVENTS` の組み合わせだった。

1. 地域プロファイルが大陸をまたぎ、出生地・人名・通貨・食文化を同じ配列から抽選していた。
2. `regionIds` 未指定のイベントは時代だけ一致すれば全地域で発火した。
3. 地域指定済みでも、旧「その他」IDや中国・ムガルをまとめて指定しているイベントがあった。
4. 「地域ごとに限定イベント5件以上」という件数検査では、文化・場所の一致を保証できなかった。

近世中国 `em_china` とムガル `em_mughal_india` 自体は変更前から別IDだった。混線の原因は共通イベント・対象地域リストにもあった。

## 今回の分割（31 → 53地域）

括弧内は時代内の出生抽選ウェイト。分割前の合計を維持する。

| 旧ID・混在範囲 | 分割後ID（ウェイト） |
| --- | --- |
| `anc_indus_other` インダス・ミケーネなど | `anc_indus` (33)、`anc_aegean` (8) |
| `cls_other` ペルシア・アフリカ・メソアメリカ・弥生日本 | `cls_persia` (9)、`cls_africa` (5、アクスム・紅海沿岸)、`cls_mesoamerica` (7)、`cls_yayoi` (3) |
| `med_other` 南アジア・アフリカ・アメリカ・アンコール | `med_india` (18)、`med_west_africa` (5)、`med_east_africa` (3)、`med_mesoamerica` (3)、`med_andes` (3)、`med_southeast_asia` (3) |
| `em_atlantic` 西アフリカ・カリブ・ブラジル・アンデス・メキシコ・北米 | `em_west_africa` (10)、`em_caribbean` (6)、`em_andes` (3)、`em_mesoamerica` (1)、`em_north_america` (3) |
| `ind_europe_us` 欧州・北米 | `ind_europe` (17)、`ind_north_america` (5) |
| `ind_india` インド・東南アジア | `ind_india` (13)、`ind_southeast_asia` (3) |
| `ind_other` ロシア・中東・アフリカ・中南米 | `ind_russia` (9)、`ind_egypt` (5)、`ind_congo` (6)、`ind_latin_america` (8) |
| `mod_china_ea` 中国・韓国・台湾 | `mod_china` (17)、`mod_korea` (1)、`mod_taiwan` (1) |
| `mod_asia` 南アジア・東南アジア | `mod_south_asia` (22)、`mod_southeast_asia` (10) |
| `mod_africa_me` サハラ以南・中東・北アフリカ | `mod_subsaharan_africa` (14)、`mod_mena` (6) |

都市・農村、人名、通貨、主食、信仰、医療・世界観の記述を分けた。旧IDを型から削除し、イベントの古い参照は型エラーにする。初期墓標もその人物の実際の舞台へ移した。ユーザーの保存済みメモリアルは地域名の文字列を持つ歴史記録なので書き換えない。

**統計の扱い**：細分化したウェイトはゲーム上の暫定配分であり、新たに出典を確認した地域別出生統計ではない。乳児死亡率・5歳未満死亡率・寿命・所得などの数値は親プロファイルを継承している。乳児死亡確率の緩和はしていない。人名は文化圏ごとの表記例で、各出生年での実在を保証する名前辞典ではない。従来の「その他」は網羅的な地理データではなかったため、新地域も世界全域を網羅するものではない。

## イベントの修正例

| 発見した混在 | 対応 |
| --- | --- |
| 三十年戦争型の傭兵が中国・ムガル・大西洋圏にも登場 | 欧州・1618〜1648年に限定、説明も欧州に統一 |
| 窓税・ガベルが古典期中国などでも発生 | 近世欧州に限定 |
| 欧州式の魔女・異端審問が中国・ムガルにも発生 | 中世・近世欧州に限定 |
| 日本式「甲種合格」「赤紙」が近代全地域で発生 | 日本に限定 |
| 第二次大戦の直接空襲が北米などでも発生 | 欧州・日本・中国・ロシアに限定 |
| 中国の領主狩猟・日本式五人組の混用 | 狩猟は封建欧州・日本に限定。連帯責任の共通文は地域固有の組名を除く |
| テオティワカン黒曜石・カナート・弥生銅鐸が同じ地域 | メソアメリカ・ペルシア・弥生日本へ振り分け |
| サハラ交易・アンデス貢納・アンコール貯水池が同じ地域 | 対応する地域へ振り分け |
| 西アフリカ出生者にもポトシ銀山・ハドソン湾猟 | 対応するアンデス・北米の場所へ限定 |
| ロシア農奴解放・スエズ・コンゴ採取・メキシコ債務農奴が同じ地域 | ロシア・エジプト・コンゴ・ラテンアメリカへ振り分け |
| 韓国・台湾でも大躍進・中国戸籍・ゼロコロナ | 中国だけに限定 |
| デリーでダッカ工場、マニラでタイ洪水など | 地域に加えて `places` で舞台を限定 |
| 大陸内陸でインド洋津波、カイロでコンゴ採掘 | 沿岸集落・コンゴ鉱山集落などに限定 |

## 再発防止の契約

`DecisionEvent` は次のどちらかを必須とする排他的な型。

- `regionIds: [RegionId, ...RegionId[]]`：少なくとも1地域を明示する。
- `allRegions: true`：内容を確認した共通イベントだけが明示的に選ぶ。

未指定・空配列を「全世界」と解釈しない。`matchesEventSetting` に時代・地域・場所・年代の照合を集約し、歴史の大波・ライフイベント・日常イベントがすべてこの判定を通る。データが型を経由せず渡された場合も、適用範囲未指定のイベントは拒否する。

`places` は地域内の都市・農村の正式表示名と一致する必要があり、テストで全参照を検査する。出生地を追加・改名するときはイベント側の参照も更新する。将来、出生地をID化する場合は表示文字列から切り離せる。

分割先に既存の固有イベントが少なくても、隣の文化圏のイベントを流用しない。プレイ可能な共通イベントの数と、特定の異地域イベントを拒否できることを検証する。新しい固有イベントの執筆は別途必要。

「世界の出来事」欄は世界史を表示する仕様のため、本人の舞台以外の話題も表示する。本人への決断イベントとは区別する。

## 次の細分化候補

今回の変更で全国家・民族・階層・年代の違いまで解決したわけではない。特に以下は残る。

| 優先 | 現在の地域 | 追加で分けたい範囲・理由 |
| --- | --- | --- |
| 高 | `em_europe`、`ind_europe`、`mod_europe` | 英仏独など。窓税とガベル、徴兵、宗教制度、通貨・人名を国別にする |
| 高 | `mod_south_asia` | インド・パキスタン・バングラデシュ。人名・宗教・通貨・制度の差 |
| 高 | `mod_southeast_asia`、`ind_southeast_asia` | インドネシア・マレー・フィリピン・タイ・ベトナム。今回の場所制限を国IDへ移行 |
| 高 | `mod_subsaharan_africa` | 西・東・中央・南部、さらに国別。文化・人名・感染症・通貨の差 |
| 高 | `mod_mena`、`med_islam` | 北アフリカ・アラブ地域・ペルシアなど。宗教圏だけでは名前・制度は一致しない |
| 中 | `em_caribbean`、`em_north_america` | 島・植民地と、先住民／移住者／被奴隷化された人々。地域だけでは社会集団の違いを表現できない |
| 中 | `cls_mesoamerica`、`med_mesoamerica` | 都市・時代別の人名資料、地域固有イベントの追加 |
| 中 | `mod_north_america`、`mod_latin_america`、`mod_russia_cis` | 国別の医療・政治制度・通貨。ソ連崩壊後のバウチャー・徴兵を共和国単位にする |
| 中 | 広い時代全般 | インダス都市とヴェーダ時代、アステカ・インカ、日本の幕藩制度などの年代条件。時代内の全出生年で同じ制度を使う問題は別に監査する |

細分化時は出生配分・生命表の出典を再評価し、親地域から継承した暫定値を置き換える。出生地ID、文化・宗教・法制度、年代ごとの政治体制を分ける設計は、その資料とともに導入する。
